A single original one-line joke about office life, written for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty. The program writes the joke to `/output/entry.txt`, where the judge reads it and compares it two at a time against the other entries. The line turns the most passive-aggressive phrase in office email — "per my last email" — into an out-of-office reply, so the punchline lands on anyone who has ever been on the receiving end of it.

## Run it

```sh
python3 main.py
```
